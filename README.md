# Best Bad Idea Builder

A fill-in worksheet based on Alex Hormozi's five-step "what business to start" framework (The Game, ep. 1014), plus an investor layer. Fill it in for any business idea, then output it as a written investor pitch (.md) or a 10-slide pitch deck (.pptx).

Open `index.html` in a browser, or publish with GitHub Pages.

When it runs outside Claude, ideas save only in that browser (localStorage), and the "Polish with Claude" button is hidden.
